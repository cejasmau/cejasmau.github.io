# Economía, ciencia de datos y otros cantares 📊🎶

> "en las vidrieras no lo vas a encontrar"

Bienvenido/a al repositorio de mi sitio personal. Este espacio explora la intersección entre la economía, la ciencia de datos y la narración, con un enfoque especial en cómo construimos y contamos historias a partir de los datos.

El sitio está construido con [Astro](https://astro.build) y utiliza el tema [Dante](https://github.com/JustGoodUI/dante-astro-theme) creado por [JustGoodUI](https://justgoodui.com/), un diseño limpio y tipográfico pensado para blogs y contenido escrito.


## Estructura del proyecto

